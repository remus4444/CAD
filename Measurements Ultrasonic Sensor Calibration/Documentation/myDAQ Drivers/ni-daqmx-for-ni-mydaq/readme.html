This file contains important information about NI-DAQmx for NI myDAQ, including system requirements, supported devices, and known issues. NI-DAQmx for NI myDAQ is intended to be used only with the NI myDAQ.

System Requirements

The following operating systems are supported: OS X 10.7 (64-bit kernel only), 10.8, and 10.9.

Refer to the LabVIEW Readme for additional system requirements and supported operating systems.

NI Application Software Support

The following table lists the NI application software versions supported by NI-DAQmx for NI myDAQ.

NI Application SoftwareVersions Supported by NI-DAQmx for NI myDAQ
NI LabVIEW 2013, 2014

Additional Software Support

If you are not using NI application software, ANSI C is also supported. Xcode versions 4.6 through 5.1 are supported.

Product Security and Critical Updates

Visit ni.com/security for security information about National Instruments products. Visit ni.com/critical-updates for information about critical updates from National Instruments.

Device and Feature Support

NI myDAQ is the only device supported in NI-DAQmx for NI myDAQ. Only features that apply to NI myDAQ are supported. There is no DAQ Assistant, NI ELVISmx soft front panel instruments, or NI MAX support.

Device Recognition and Configuration

Launch System Preferences, and click the NI myDAQ icon to discover, configure, rename, and delete devices and to launch NI-DAQmx Test Panels.

Known Issues

You can access the software and documentation known issues list online. Refer to the NI-DAQmx for NI myDAQ website for an up-to-date list of known issues in NI-DAQmx for NI myDAQ.

Finding Examples and Documentation

To find examples within LabVIEW, go to Help»Find Examples. To find documentation, including help for NI-DAQmx VIs, go to /Applications/National Instruments/NI-DAQmx. Accessing all the NI-DAQmx for NI myDAQ documentation requires a web connection.
